# Sleek Gray Resume Template

A minimal, sleek, and simple resume template inspired by Archcraft's aesthetic.

## Features
- Sleek dark gray theme
- Simple and clean layout
- Responsive design (Bootstrap 5)
- Easy to customize

## Getting Started
1. Clone the repository.
2. Open `index.html` in your browser to preview.
3. Edit `index.html` and `assets/css/styles.css` to fill in your information.
